# Contributing

## Branches

Each active team member has their own personal branch.

Example:

member/saransh
member/mahak
member/nithin
member/swathi

## Workflow

1. Pull the latest main branch.
2. Work on your personal branch.
3. Test your changes.
4. Commit meaningful work.
5. Push your branch.
6. Open a pull request.
7. Team lead reviews the changes.
8. Approved changes are merged into main.

## Commit Messages

Use meaningful commit messages.

Examples:

feat: add workflow node validation
fix: handle invalid tenant ID
test: add workflow validation tests
docs: update API documentation

## Important

Never commit:

- .env files
- passwords
- API keys
- database credentials
- generated dependencies
