**Event contract as built**

```json
{
  "type": "execution.updated | execution.completed | execution.failed",
  "data": {
    "executionId": "<24-hex string>",
    "workflowId": "<24-hex string>",
    "status": "<persisted status string>",
    "updatedAt": "<ISO-8601 UTC>"
  }
}
```

Status mapping (`executionWebSocket.ts:37-50`): `queued`, `running`, `compensating` →
`execution.updated`; `completed` → `execution.completed`; `failed` → `execution.failed`;
`compensated` and `compensation_failed` → **no event**, deliberately unmapped.
